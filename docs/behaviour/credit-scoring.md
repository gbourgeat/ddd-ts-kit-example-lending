### score (value object), in unit

`unit/score.vo.spec.ts`

- **Score**
  - is equal to another score with the same value
  - accepts the whole numbers from 0 to 100 as scores
  - refuses a score above 100 with the code INVALID_SCORE
  - refuses a score below 0 with the code INVALID_SCORE
  - refuses a score that is not a whole number with the code INVALID_SCORE
  - puts a score below 40 in the red band
  - puts a score of 40 in the amber band
  - keeps a score of 69 in the amber band, never shown green
  - puts a score of 70 in the green band, the only band an advisor decides with

### scoring-model (aggregate), in unit

`unit/scoring-model.aggregate.spec.ts`

- **ScoringModel**
  - is born with its identity and no version
  - is rehydrated in its stored state without recording a new fact
  - numbers the first published version 1, with its label and model risk
  - numbers each next version after the last one published
  - records the fact of each publication, with the version it announces
  - refuses a blank label and publishes no version
  - records nothing as long as no business intention is expressed
