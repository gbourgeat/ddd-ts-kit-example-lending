## Acceptance specs

### us0 (acceptance), in acceptance

`acceptance/us0.acceptance.spec.ts`

- **US0, acceptance**
  - a customer of the bank submits an application for one loan and gets back its identifier, a Location and the amount in whole cents

  - the submission is published once, as an integration event carrying the application identifier, in the same transaction that records it
