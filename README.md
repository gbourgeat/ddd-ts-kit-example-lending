# Lending

A lending platform for regional banks and credit unions, built with
[ddd-ts-kit](https://github.com/gbourgeat/ddd-ts-kit) as a showcase of a regulated domain:
relationship-based access control, event-sourced application files and loan ledgers, delegated
credit decisions, anti-money laundering and consumer credit rules.

The statement of needs is [docs/architecture/needs.md](docs/architecture/needs.md). The project is
built by coding agents on a published version of the kit, each step measured; see
[docs/tooling](docs/tooling).
